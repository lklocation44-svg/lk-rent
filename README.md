# LK RENT

Site complet front-end de l’agence de location de voitures premium à Brest.

- Catalogue des 9 véhicules et tarifs/cautions fournis par LK RENT
- Calcul des formules 24H, 48H, 72H, 4 jours et semaine complète
- Récapitulatif prix + caution avant envoi
- Détection des chevauchements de réservation dans le navigateur
- Pages Conditions et Contact
- Tableau d’administration des demandes et disponibilités
- Design responsive mobile

Le site est une application statique. Les demandes et réglages de l’espace admin sont stockés dans `localStorage` : pour une exploitation commerciale multi-utilisateur, il faut connecter une base de données, une authentification serveur et un service d’e-mail/paiement.

## Déploiement GitHub Pages

Dans GitHub : **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
